# Nexus CRM

A CRM with multiple pipelines, Kanban boards, and team management, built on Cloudflare Pages, Pages Functions, and D1.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set up the local database:
   `npm run db:setup`
3. Run the app:
   `npm run dev`
